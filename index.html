❄️ Snowflake Integration

Knowledge That Scales

Snowflake serves as the curated knowledge backbone for architectural pattern retrieval and versioned evaluation benchmarks — never for raw source code storage.

📚
Architectural Pattern Knowledge Base
Curated catalogue of Strategy, Repository, Adapter, Pub/Sub, and 10+ patterns with trade-offs and code examples. Retrieved via Cortex vector search.
📊
Versioned Evaluation Benchmarks
Ground-truth benchmark cases for measuring detector precision, recall, and F1. Each run is recorded for reproducible comparison across model versions.
📐
Architecture Rules Store
Machine-verifiable rules authored in Archy are persisted in Snowflake and synced to Dev's real-time boundary checker in VS Code.
🔒
Privacy-Safe Analytics
Aggregate scan metrics and finding feedback — no raw source code, file paths, or secrets ever stored. SHA-256 session hashing only.

🛡️ Safety Guardrails

Built on 10 Core Principles

Every feature is designed around a non-negotiable set of product principles.

01
Understand Before Suggesting
Inspect relevant project context before recommending a change.
02
Reuse Before Reinventing
Prefer suitable existing functions and installed dependencies.
03
Smallest Safe Change
Prefer minimal, reviewable patches over broad rewrites.
04
Evidence Over Confidence
Explain the evidence behind a finding; distinguish facts from hypotheses.
05
Developer Remains in Control
No unapproved edits, installs, uploads, or destructive actions.
06
Privacy by Design
Minimise collected context; make remote processing explicit and configurable.
07
Validate, Don't Assume
Tests and static checks provide evidence, not proof of correctness.
08
Architecture and Code Stay Connected
Architecture decisions must be inspectable and usable by Dev.
09
Be Quiet When Uncertain
Avoid repeated or low-confidence warnings.
10
Useful Over Flashy
Measure correctness, signal quality, and developer time saved.
